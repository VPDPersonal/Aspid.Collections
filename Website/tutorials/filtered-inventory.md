title: "Search and categories"
---

Scene · `FilteredInventory.unity`

Select the sample component and set the category and search text before pressing Play. With the default weapon category, the Console first lists two swords. Adding Dragon Slayer inserts it in alphabetical order. During Play, code can call `SetSearch` or `SetCategory` to rebuild the matching view.

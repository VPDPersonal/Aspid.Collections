Если при установке 1.1.0 Package Manager не находит Unity Test Framework 1.6.0, обновитесь до 1.1.1. В этой версии зависимость удалена. Также исправлена подписка через ковариантные интерфейсы. Синхронизированные словари и множества сохраняют компараторы источника, а синхронизированный стек сохраняет исходный порядок элементов.

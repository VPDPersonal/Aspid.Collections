Отфильтрованные списки начали обрабатывать типовые изменения источника поэлементно. Синхронизированные представления получили поддержку дополнительных пакетных операций. В пакет вошли пять примеров для Unity.

При обновлении с 1.0.x замените идентификатор пакета в `Packages/manifest.json` с `com.aspid.collections` на `tech.aspid.collections`.

[Полный список изменений](https://github.com/VPDPersonal/Aspid.Collections/blob/main/CHANGELOG.md) · [Выпуски на GitHub](https://github.com/VPDPersonal/Aspid.Collections/releases)

---
title: "Таблица очков по ID игрока"
---

Сцена · `Leaderboard.unity`

В Console проследите, как результат игрока `p-001` меняется со 100 до 150 очков. После двух добавлений, замены и удаления в таблице остаётся один игрок. Обработчик берёт ID из пары «ключ — значение», чтобы определить строку для обновления. [LeaderboardSample.cs](https://github.com/VPDPersonal/Aspid.Collections/blob/main/Aspid.Collections/Packages/tech.aspid.collections/Samples~/04_DictionaryKeyedTable/LeaderboardSample.cs)

## Попробуйте изменение

Добавьте пару участников, переместите первого и включите фильтр. Данные остаются в одном источнике, а его потребители реагируют на изменения.

## Пять коллекций. Практические примеры.

<SampleAvailability />

| Коллекция | Задача | Пример |
| --- | --- | --- |
| `ObservableList<T>` | Состав отряда с пакетным добавлением и сохранением карточек | [Squad Roster](/tutorials/squad-roster) |
| `ObservableDictionary<TKey, TValue>` | Результаты игроков по постоянному ID | [Match Scoreboard](/tutorials/match-scoreboard) |
| `ObservableHashSet<T>` | Уникальные посетители и отключаемая сигнализация | [Zone Occupancy](/tutorials/zone-occupancy) |
| `ObservableQueue<T>` | Обработка заказов в порядке поступления | [Crafting Queue](/tutorials/crafting-queue) |
| `ObservableStack<T>` | История отмены в обратном порядке | [Crafting Queue](/tutorials/crafting-queue) |

Для поиска и сортировки начните с [Item Browser](/tutorials/item-browser). Каждый пример содержит готовую сцену Unity, локальные шрифты, кнопки, живые счётчики и упражнение. [Все примеры](/tutorials).

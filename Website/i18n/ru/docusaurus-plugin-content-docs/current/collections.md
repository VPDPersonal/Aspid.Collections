# Выбор коллекции

## Форма данных

| Тип | Порядок и идентичность | Основные операции |
| --- | --- | --- |
| `ObservableList<T>` | Упорядоченный список с индексами; дубликаты разрешены | Add, Insert, RemoveAt, Move, AddRange, InsertRange, RemoveRange |
| `ObservableDictionary<TKey, TValue>` | Постоянные ключи; порядок перечисления не определяет рейтинг | Add, присваивание по индексу, Remove, TryGetValue |
| `ObservableHashSet<T>` | Уникальность по comparer; порядок не определён | Add, Remove, Contains |
| `ObservableQueue<T>` | Первым пришёл — первым вышел | Enqueue, EnqueueRange, Dequeue, TryDequeue, DequeueRange |
| `ObservableStack<T>` | Последним пришёл — первым вышел | Push, PushRange, Pop, TryPop, PopRange |

Все пять поддерживают `Clear`, `Dispose`, уведомления, `SyncRoot` и `CreateSync`. У Dictionary и HashSet нет публичных методов пакетного изменения. Для пакетного удаления из Queue/Stack передайте выходной массив, длина которого равна числу удаляемых элементов; нехватка элементов проверяется до изменения.

## Контракт только для чтения

| Источник | Интерфейс потребителя |
| --- | --- |
| List | `IReadOnlyObservableList<T>` |
| Dictionary | `IReadOnlyObservableDictionary<TKey, TValue>` |
| Queue, Stack, HashSet | `IObservableCollection<T>` |
| Отфильтрованное представление | `IReadOnlyFilteredList<T>` |

Интерфейсы списка, коллекции и фильтра ковариантны по типу элемента. Интерфейс словаря инвариантен. Эти интерфейсы источников и фильтров не управляют освобождением: отдельно храните конкретного владельца. `CreateSync` возвращает освобождаемые интерфейсы только для чтения.

## Равенство и ключи

Передайте comparer словарю или множеству, если нужны строки без учёта регистра или другое правило равенства. Повторное добавление в множество возвращает `false` без уведомления. Присваивание в словарь заменяет существующий ключ или добавляет отсутствующий. Для рейтинга явно отсортируйте отображаемую проекцию, не полагаясь на порядок словаря.

`ObservableListExtensions.Swap` находится в `Aspid.Collections.Observable.Extensions`. Он использует перемещения, поэтому слушатели могут получить несколько уведомлений; это не атомарная пакетная операция.

## Потоки

Основные операции и перечисление защищены `SyncRoot`. Уведомления синхронно выполняются на изменяющем потоке внутри блокировки операции. Перечислители основных коллекций держат блокировку на всё время активного перечисления. `Keys` и `Values` словаря — живые представления; блокировка getter не защищает их дальнейшее перечисление.

Это не общая гарантия безопасного связывания UI между потоками. Самостоятельно согласуйте изменение подписок, передавайте UI-работу на его поток и используйте `FilteredList` с одного потока. Не держите перечислители во время асинхронной работы. Подробнее — [жизненный цикл и безопасность событий](lifecycle.md).

---
title: Синхронизированные представления
---

Используйте `CreateSync`, чтобы преобразовать каждый элемент источника в удобный для потребителя тип. К моменту возврата из метода представление уже содержит преобразованные элементы. Последующие изменения коллекции автоматически обновляют представление.

## Преобразуйте список

```csharp
using System;
using Aspid.Collections.Observable;
using Aspid.Collections.Observable.Synchronizer;

using var scores = new ObservableList<int> { 12, 30 };
using var labels = scores.CreateSync(score => $"{score} XP");

scores.Move(0, 1);
scores[1] = 15;
Console.WriteLine(string.Join(", ", labels)); // 30 XP, 15 XP
```

Меняйте исходный список. Доступная для чтения проекция сохраняет его порядок. Перемещение переносит уже созданный результат, а замена элемента вызывает преобразователь для нового значения. Если поля объекта могут меняться внутри коллекции, подпишите представление на изменения самого объекта или явно замените элемент коллекции.

## Выберите представление для коллекции

Список возвращает `IReadOnlyObservableListSync<T>` с доступом по индексу. Словарь сохраняет ключи и преобразует значения в `IReadOnlyObservableDictionarySync<TKey, T>`. Очередь, стек и множество возвращают `IReadOnlyObservableCollectionSync<T>` для перебора и подписки. Для множества разным исходным элементам должны соответствовать разные результаты.

## Освободите созданные элементы

Передайте `isDisposable: true`, если представление владеет каждым созданным элементом и тот реализует `IDisposable`. Для другого способа освобождения передайте второй делегат, например `models.CreateSync(CreateRow, ReturnRowToPool)`. При удалении строки из источника освобождается её проекция. Вызов `Dispose()` у представления снимает подписку и освобождает оставшиеся проекции. Подробнее об этом в [руководстве по времени жизни](./lifetime.md).

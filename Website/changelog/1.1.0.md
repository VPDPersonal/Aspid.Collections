title: "1.1.0"

Filtered lists began handling common source edits incrementally. Synchronized views gained batch propagation for more operations. The package added five importable Unity samples.

When upgrading from 1.0.x, change the package identifier in `Packages/manifest.json` from `com.aspid.collections` to `tech.aspid.collections`.

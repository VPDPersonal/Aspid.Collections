<p className="readme-lede">Keep your data, views and filtered lists in step. Aspid.Collections adds change notifications to familiar collections, projects models into disposable views, and keeps search and sort results up to date.</p>

## Try a change

Add a pair, move the first member, then filter the view. The data stays in one source; its consumers react to changes.

<CollectionsDemo />

## Install

<InstallPanel url="https://github.com/VPDPersonal/Aspid.Collections.git#upm" />

Requires **Unity 2021.3.0f1+**. The runtime has no Unity engine references and can also be compiled in a .NET project. [Installation and version pinning](installation.md).
